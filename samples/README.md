# サンプル音源（オプション）

このディレクトリは、外部サンプル音源を使用したい場合のために用意されています。

## 🎹 現在の仕様

**デフォルトでは、このアプリケーションはTone.jsシンセサイザーを使用します。** 外部音源ファイルは不要です。

使用しているシンセサイザー：
- **Kick**: Tone.MembraneSynth - 低音域のメンブレンシンセ
- **Snare**: Tone.NoiseSynth - ホワイトノイズベース
- **Hi-Hat**: Tone.MetalSynth - メタリックなサウンド
- **Bass**: Tone.MonoSynth - スクエア波ベース

## 📁 外部サンプルの使用（オプション）

より本格的なドラムサウンドを使用したい場合は、以下のファイルを配置できます：

- `kick-01.wav` - キックドラム
- `snare-01.wav` - スネアドラム
- `hat-closed-01.wav` - クローズド・ハイハット

## 音源の入手方法

以下のようなCC0/パブリックドメインの音源サイトから入手できます：

- [Freesound](https://freesound.org/) - CC0フィルターで検索
- [99sounds](https://99sounds.org/) - フリーサンプルパック
- [BBC Sound Effects](https://sound-effects.bbcrewind.co.uk/) - BBC提供の効果音

または、任意のDAW/サンプルパックから書き出したWAVファイルをご利用ください。

## ライセンス

このディレクトリに配置する音源は、CC0またはパブリックドメインのものを使用してください。
商用利用する場合は、必ずライセンスを確認してください。
